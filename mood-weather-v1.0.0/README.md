# 心情天气 · Mood Weather

v1.0.0 原型快照，冻结于 2026-10-30。

结合面部表情分析与自主心情记录的移动网页原型。使用 EmotiEffLib 的 enet_b2_8 模型分析用户主动拍摄的照片，用户通过五个心情选项记录自身感受，并在「心流」回顾趋势和照片。

## 本机启动

已在 Apple Silicon Mac、Python 3.9 环境测试。首次安装需要联网下载依赖和模型。

```sh
sh setup.sh
.venv/bin/python server.py
```

打开 http://127.0.0.1:8766 。手机布局可在窄窗口预览；真实手机摄像头访问需要另外配置 HTTPS，本仓库不包含临时隧道或访问密码。

## 功能

- 主动拍照、定格画面后分析八类表情，展示前三项
- 自选五档心情、可选备注、保存照片
- 按日回顾曲线和记录、大图左右切换
- 数据保存在当前浏览器的 localStorage；画面在本机服务内存中分析

## 已知限制

这是可演示原型，不是已验证的情绪测量产品。表情分类不等于用户真实心情；存在误判。照片保存在浏览器，受容量限制，不跨设备同步。当前存在手机浏览器和摄像头兼容性验证不足，亦未完成自动化端到端测试。曲线基于用户自评的每日平均值，不是模型推断的开心值。

旧版试验文件、个人记录、照片、模型权重、运行依赖和隧道密码未包含在快照内。product/assets 为历史视觉实验保留资源，当前天空效果使用 CSS。
